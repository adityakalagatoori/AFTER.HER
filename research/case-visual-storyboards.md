## What makes each case visually distinct (shared system, varied content)
All six share one dossier template (5 chapters + legal journey + sources + Evidence Mode), by design — the brief's "don't reuse the exact same sequence" is addressed through **what fills the template**, not a different template per case: different number of timeline nodes (3–4, matching actual documented complexity), different institutional photograph, different filter tags, different presence/absence of the identity-protected tag, and chapter text lengths that vary with how much is actually verifiable (Kathua and Hathras's "Before" chapters are deliberately shorter than Bhanwari Devi's or Bilkis Bano's, because less is public and more is protected).

## What this storyboard does NOT include
No "final image" per case beyond the one institutional photograph each already has — a second or third image per case was targeted in the original brief, but this pass prioritized getting one fully verified, non-identifying, narratively-placed image per case over partially-verified additional images. Expanding beyond one image per case would need another dedicated research pass, each image individually verified and visually inspected the same way these six were.
